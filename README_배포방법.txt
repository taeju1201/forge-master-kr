Forge Master 한국어 플래너 v1
=============================

[사용 목적]
- 카카오톡 링크에서 바로 열리는 독립 정적 웹앱입니다.
- Google Apps Script / Google Sheets가 필요 없습니다.
- 갤럭시, 아이폰, PC 브라우저에서 사용할 수 있습니다.

[GitHub Pages 올리는 법]
1. GitHub에서 새 Public 저장소를 만듭니다. 예: ForgeMaster-KR
2. 이 ZIP을 압축 해제합니다.
3. index.html, styles.css, app.js, manifest.webmanifest, sw.js를 저장소 최상단(root)에 업로드합니다.
4. 저장소 Settings -> Pages로 이동합니다.
5. Build and deployment에서 Deploy from a branch 선택
6. Branch: main / Folder: /(root) 선택 후 Save
7. 잠시 뒤 https://계정명.github.io/ForgeMaster-KR/ 주소가 생성됩니다.
8. 그 주소를 카카오톡에 보내면 인앱 브라우저에서 바로 열 수 있습니다.

[데이터]
- Forge Master 2.8.2에서 확인한 게임 설정 구조를 기준으로 제작했습니다.
- 상세 설정은 2026-08-21 parsed config JSON을 읽습니다.
- 첫 접속에는 인터넷 연결이 필요합니다.
- 기술/클랜/레벨 설정은 브라우저 localStorage에 저장됩니다.

[현재 포함]
- 기술 트리 효과 설정
- 클랜 기술 효과 설정
- 기술/클랜 효과 통합 적용
- 대장간 Lv.1~35 비용/시간 계산
- 무기별 선딜/공격주기/초당 공격횟수/공격범위
- 기본/증가/최종 이동속도 및 공격범위
- 스킬 레벨별 피해/체력 + 기술 보정
- 펫/탈것 레벨별 피해/체력 + 기술/클랜 보정
- 던전 단계별 적 피해/체력 및 보상
- 리그별 순위 보상
- 클랜 등급별 승리/패배 보상 + 클랜 기술 보정
- 모바일 메뉴 및 카카오톡 인앱 브라우저 대응

[주의]
- 기본 이동속도의 절대값은 게임 설정에서 확정하지 못해 직접 입력합니다.
- 일부 계산은 내부 StatNature를 바탕으로 한 예상 계산이며 화면에 구분해서 표시됩니다.
- 게임 업데이트 후 수치가 달라질 수 있습니다.


[개인 설정 저장 방식]
- 이 버전은 계정/비밀번호가 없습니다.
- 기술트리, 클랜기술, 대장간 레벨 등 사용자가 입력한 값은 각 사용자의 브라우저 localStorage에만 저장됩니다.
- 같은 GitHub Pages 주소를 여러 클랜원이 사용해도 서로의 설정은 공유되지 않습니다.
- 단, 같은 기기/같은 브라우저 프로필을 같이 쓰면 그 브라우저에 저장된 설정은 같이 보일 수 있습니다.
- 브라우저 데이터 삭제 또는 시크릿 모드 사용 시 저장값이 사라질 수 있습니다.
